# PROJECT: VONDRAG
## Desenhos Mágicos — Guia simples

**Versão simplificada do capítulo de regras 1.0**

> Forma = o que a magia faz. Elemento = do que ela é feita. Aprimoramento = o que muda.


## 1. Entenda a ideia

Em **Vondrag**, magia é criada por desenhos. Merlin descobriu que o mineral **Nexus** libera Energia Arcana e desenvolveu uma forma de conduzir essa energia usando figuras geométricas e símbolos elementais.

> **A regra mais importante**
> **Forma** diz o que a magia faz. **Elemento** diz do que ela é feita. **Aprimoramentos** ajustam o resultado.

Você não precisa decorar uma lista de feitiços. Pode combinar símbolos para construir o efeito que quiser, respeitando as funções de cada um.

> **Primeiro exemplo**
> **Círculo + Fogo = Projétil de Fogo.** O Círculo cria o projétil; Fogo define o elemento. Pronto: já existe uma magia básica.


## 2. As três formas mágicas

| Forma | Para que serve | Exemplo simples |
|---|---|---|
| Círculo | Cria um projétil ou marca uma área. | Bola de Fogo. |
| Quadrado | Cria uma parede/estrutura ou guarda um efeito. | Parede de Terra. |
| Triângulo | Controla uma manifestação do mesmo elemento ou focaliza magia em um objeto visível. | Mover uma parede de Terra. |

**Círculo:** sua escala inicial é de **3 metros**. Cada Círculo extra desenhado apenas para ampliar a escala acrescenta **2 metros**. A medida exata (raio ou diâmetro) ainda não foi definida.

**Triângulo:** alcança **6 m no Tier 1**, **8 m no Tier 2** e **10 m no Tier 3**. Para controlar uma manifestação, seu elemento deve ser o mesmo da manifestação controlada.

> **Exemplo de controle**
> Uma parede de **Terra** pode ser movida por um Triângulo de **Terra**. Um Triângulo de **Água** não pode controlar essa parede.


## 3. Escolha um elemento

Cada magia utiliza pelo menos um dos seis elementos. Escolha a propriedade que melhor representa o efeito desejado; não é obrigatório usar todas as propriedades de uma vez.

| Elemento | Efeitos disponíveis |
|---|---|
| Fogo | Dano, Combustão, Empurrão, Calor |
| Água | Cura de efeito, Fluidez, Pressão, Gelo |
| Terra | Defesa, Peso, Esmagamento, Armadilhas |
| Grama | Cura, Veneno, Raízes, Crescimento |
| Gelo | Congelamento, Redução de Velocidade, Fragilidade |
| Raio | Perfuração, Velocidade, Paralisia |

> **Exemplo**
> Raio pode ser escolhido para causar **Perfuração** numa manifestação ofensiva ou para aplicar **Paralisia** como um efeito armazenado.


## 4. Entenda o Tier

O **Tier** é o nível de complexidade do desenho. Ele limita quantas formas diferentes você combina e quantos aprimoramentos pode usar.

| Tier | Formas funcionais (máximo) | Aprimoramentos (máximo) |
|---|---|---|
| 1 | 1 | 4 |
| 2 | 2 | 8 |
| 3 | 3 | 12 |

Uma magia de Tier 3 pode usar apenas uma forma, se o jogador quiser. O Tier **não obriga** uma magia a causar dano.

**Importante:** formas funcionais são as camadas que acrescentam novas funções. Círculos extras usados apenas para ampliar uma área não contam como novas funções.


## 5. Misture formas para criar magias novas

A partir do Tier 2, você pode colocar uma forma dentro da outra. Leia o desenho **de fora para dentro**. A forma externa estabelece a manifestação principal; as internas acrescentam funções. **A ordem importa.**

| Desenho | O que acontece |
|---|---|
| Círculo → Triângulo | Projétil guiado, se ambos tiverem o mesmo elemento. |
| Círculo → Quadrado | Projétil que carrega um efeito armazenado. |
| Quadrado → Triângulo | Parede ou estrutura controlável, com elemento correspondente. |
| Quadrado → Quadrado | Parede com efeito armazenado. |
| Triângulo → Círculo | Projeção remota, respeitando o alcance. |

No **Tier 3**, você pode usar uma terceira forma. Exemplo: **Quadrado de Terra → Quadrado de Raio → Triângulo de Terra**. O resultado é uma parede de Terra que pode ser movimentada e guarda um efeito de Raio.

*Outras sequências, inclusive formas repetidas, podem existir. Cada forma precisa ter uma função compreensível; repetir uma forma não cria ataques ou dano extra automaticamente.*


## 6. Fusão não é armazenamento

Existem duas maneiras de usar elementos diferentes. **Não confunda as duas.**

| Situação | Significado |
|---|---|
| Fusão: Fogo + Raio na mesma camada | Os dois viram um novo elemento: **Plasma**. |
| Composição: Fogo numa camada + Raio armazenado em outra | Continuam separados. O Raio é aplicado quando o armazenamento ativa. |

A fusão **Fogo + Raio = Plasma** está definida. Tentar fundir **Fogo + Água** é incompatível. Entretanto, usar Fogo e Água **em camadas separadas** não gera automaticamente essa falha.

As demais combinações de fusão apresentadas durante o desenvolvimento ainda precisam de confirmação; estão reunidas no final como **material em teste**.


## 7. Como funcionam os aprimoramentos

| Símbolo | Função | Regra rápida |
|---|---|---|
| Diamante | Muda uma variação de elemento **puro**. | Não funciona em fusões. Ex.: Fogo Explosivo. |
| Estrela | Aumenta a duração de uma **condição**. | Cada Estrela: +1 turno. |
| Hexágono | Aumenta a permanência de uma **estrutura/campo**. | Cada Hexágono: +1 turno. |

> **Duas contas simples**
> **Estrutura:** 2 turnos + quantidade de Hexágonos.
> **Condição:** 1 turno + quantidade de Estrelas.

Por exemplo: parede com **2 Hexágonos** dura **4 turnos**. Paralisia armazenada com **2 Estrelas** dura **3 turnos** em cada alvo atingido. As duas durações são independentes.

Efeitos instantâneos não viram condições duradouras só porque receberam uma Estrela. Todos os aprimoramentos usados nas camadas somam para o limite do Tier.


## 8. Armazene um elemento dentro de outro

Um **Quadrado** pode guardar a propriedade de um elemento **dentro de uma manifestação criada por outra forma**. O efeito fica guardado até acontecer o gatilho adequado.

> **Regra essencial**
> O elemento armazenado **não causa dano direto adicional**. Ele apenas aplica a propriedade escolhida: Paralisia, Congelamento, Raízes, Veneno etc.


### Quando o efeito é liberado?

| Onde está guardado | Quando ativa | O que acontece depois |
|---|---|---|
| Dentro de um projétil | No **impacto**. | Aplica o efeito armazenado, sem dano extra. |
| Dentro de uma parede | Quando alguém **toca**, **quebra**, ou **toca/quebra**, segundo o gatilho escolhido. | Pode reaplicar o efeito a diferentes alvos enquanto a parede existir. |

Uma parede **não perde** seu efeito no primeiro contato. Quando deixa de existir, para de aplicá-lo. Se for destruída e a quebra for seu gatilho, ela pode liberar o efeito nesse momento.

Cada alvo afetado recebe sua própria duração de condição. A condição pode continuar depois que a parede desaparecer.

*Ainda não foi decidido se contatos repetidos do **mesmo alvo** renovam ou acumulam uma condição. Outros tipos de estrutura também precisam de gatilhos próprios.*


## 9. Como o Triângulo controla uma magia

Para **Controle Elemental**, o Triângulo deve ter o **mesmo elemento da manifestação** que pretende controlar. O jogador também precisa indicar qual manifestação é o alvo do controle.

| Manifestação | Triângulo | Pode controlar? |
|---|---|---|
| Parede de Terra | Terra | Sim |
| Projétil de Fogo | Fogo | Sim |
| Parede de Terra | Água | Não |
| Projétil de Plasma | Fogo | Não |

Uma manifestação de Plasma não pode ser controlada por um Triângulo de Fogo como se Plasma fosse Fogo puro. O Triângulo deve corresponder ao **elemento resultante**. A forma exata de desenhar esse controle de fusão ainda será detalhada.

A função **Foco em Objeto** continua independente: ela permite focalizar o próprio elemento em um objeto visível dentro do alcance do Tier, mas não dá controle sobre elementos diferentes.


## 10. Dano e falhas

O dano direto pertence à **manifestação ofensiva** (por exemplo, o projétil). Elementos armazenados aplicam efeitos, mas **não somam dano**. Magias de Cura, Defesa ou Controle podem não causar dano algum.


### Dano direto — valores ainda em teste

| Tier | Magia ofensiva pura | Magia ofensiva fundida |
|---|---|---|
| 1 | 3 Tokens | 4 Tokens |
| 2 | 5 Tokens | 6 Tokens |
| 3 | 7 Tokens | 8 Tokens |

Esses números são uma **proposta de balanceamento**, não uma regra definitiva. Se forem usados numa sessão de teste, a fusão concede +1 Token apenas à manifestação ofensiva principal.


### Falha ao fundir elementos incompatíveis

| Tier | Falha | Dano ao conjurador |
|---|---|---|
| 1 | Explosão de carvão | 1 Token |
| 2 | Explosão química | 2 Tokens |
| 3 | Expansão de mercúrio | 3 Tokens |

Esta tabela vale para **falhas de fusão**, não para elementos diferentes guardados em camadas distintas. Acerto de magia e resistência contra condições ainda dependem das regras gerais da mesa.


## 11. Crie uma magia em seis passos

1. **Decida o efeito.** Quer um projétil, uma parede, um foco ou um efeito armazenado?

2. **Escolha o Tier.** Isso determina o limite de formas e aprimoramentos.

3. **Desenhe a forma principal.** Ela determina o que surge na magia.

4. **Escolha o elemento.** Acrescente até mais duas camadas se o Tier permitir.

5. **Use aprimoramentos.** Estrelas para condições, Hexágonos para estruturas e Diamantes somente para elementos puros.

6. **Confira o resultado.** Verifique controle, gatilho, duração, fusões e dano (se houver).


## 12. Três magias prontas para aprender

> **MAGIA 1 · Bola de Fogo · Tier 1**
> **Desenho:** Círculo de Fogo.
> **Resultado:** lança um projétil de Fogo.
> **Para aprender:** uma única forma e um único elemento já criam uma magia.

> **MAGIA 2 · Rocha Paralisante · Tier 2**
> **Desenho:** Círculo de Terra → Quadrado de Raio (Paralisia).
> **Resultado:** o projétil de Terra causa o dano principal e, ao atingir, aplica Paralisia por **1 turno**. O Raio armazenado causa **0 dano extra**.
> **Para aprender:** armazenamento é diferente de fusão.

> **MAGIA 3 · Muralha Paralisante · Tier 3**
> **Desenho:** Quadrado de Terra (Parede, 2 Hexágonos) → Quadrado de Raio (Paralisia, 2 Estrelas) → Triângulo de Terra (Controle).
> **Resultado:** a parede dura **4 turnos** e pode ser movimentada pelo Triângulo de Terra. Quem ativar o gatilho recebe Paralisia por **3 turnos**. A parede pode reaplicar o efeito enquanto existir.
> **Para aprender:** estrutura e condição têm durações separadas.

## 14. Regras que ainda estão em teste

O sistema acima já permite jogar. Os pontos a seguir **não devem ser tratados como decisões definitivas**:

- Dano mágico: escala 3/5/7 Tokens (+1 por fusão ofensiva).
- Reaplicação da mesma condição ao mesmo alvo: renovar, manter ou acumular.
- Gatilhos de estruturas diferentes de projéteis e paredes.
- Como desenhar o vínculo de um Triângulo com uma fusão.
- Fusões propostas abaixo e a incompatibilidade Fogo + Gelo.
- Definição de raio/diâmetro na escala do Círculo, além de regras específicas de resistência a magia.
